# AI Agentic Assistant — One-Page Pitch

## The Problem

Indian SMBs need AI for 12+ daily jobs — GST filing, customer support, social media, HR, sales outreach — but:
- Separate SaaS tools cost ₹5,000–₹50,000/month combined
- Most tools aren't built for Indian rules (GST, TDS, Tamil/Hindi, UPI)
- No single platform covers finance + support + marketing together

## The Solution

**AI Agentic puts 24+ business AI assistants behind one login.**

An admin decides exactly which tools each client can use, on Free / Pro / Enterprise plans, billed in INR (UPI) or globally (Stripe).

```
One login → pick your tools → AI does the work
GST calc, customer replies, LinkedIn posts, HR screening — all in one place
```

## Product

- **3 live AI agents:** Customer Support (38 features), CA Accounting (40 features), Social Media
- **India-first:** GST engine, Tamil/Hindi language support, UPI/Razorpay billing
- **Multi-tenant:** per-client tool entitlements, Admin Panel, plan gating
- **Demo Mode:** zero-cost public demo (no API keys needed)
- **Stack:** FastAPI + React 18 + Ollama LLM + TypeScript
